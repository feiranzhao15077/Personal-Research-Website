## 尺寸、方向与落地

- 单位：**米**；不需要额外乘以 0.001。
- **+Y 向上，+Z 指向车头**；采用 glTF 右手坐标系，**+X 为车辆左侧**（FL/RL 位于 X>0）。
- 车体在水平 XZ 平面居中；轮胎最低点位于 **Y=0**，仅存在浮点舍入误差。
- 实际包围盒：长 **0.600000 m**、宽 **0.400000 m**、高 **0.450000 m**。
- 轻量版高度约 **0.449953 m**；局部倒角简化引起的差异小于 0.1 mm。
- 对应名义尺寸：**600×400×450 mm**；轮径 150 mm；轴距 380 mm。
- 网页侧坐标范围约为 X=±0.200、Z=±0.300、Y=0～0.450 m。

## 部件与未来动作

- `Radar_Car`：整个小车根节点，网页整体旋转请作用于此节点。
- `Main_Chassis`、`Body_Shell`、`Suspension_System`：底盘、外壳与悬挂装配。
- `Radar_Assembly`、`Radar_Gimbal`：雷达总成与偏航轴心。
- `Radar_Elevation_Pivot`、`Radar_Panel_Frame`、`Radar_Panel`：俯仰轴心、面板支架与面板。
- `Wheel_FL`、`Wheel_FR`、`Wheel_RL`、`Wheel_RR`：四轮轴心，位于各自车轮中心。
- 完整版保留 `Battery_Module`、`AI_Computer`、`Communication_Board`、`Radar_Processor`。

GLB 为装配状态的静态资源。Blender 驱动器、约束求解和转台动作不导入网页；后续网页动作需自行驱动上述节点。
部件保持父子关系和原机械轴心；请在正确的父节点/局部坐标系下应用旋转，而不要假定所有局部轴与世界轴一致。
小型同材质表面按所属装配合并，以减少绘制调用；车轮、雷达与车身没有合并为一个整体。

## PBR 材质与导出处理

- 使用可导出的 Principled / glTF 金属度—粗糙度 PBR 材质。
- 基础颜色、金属度、粗糙度和蓝色 LED 自发光由标准材质参数提供。
- Blender 专用细粒噪声效果已由内嵌切线空间法线 PNG 表示；未连接的程序化 Noise/Bump 节点已从准备副本删除。
- 全部材料为 **OPAQUE**；镜头沿用原模型的不透明深色涂层玻璃外观，不依赖透明混合。
- 去除零面积/零法线退化三角面，保留可见轮廓与有效表面法线。
- 内嵌贴图没有外部路径依赖。

桌面和高性能设备使用 `j20.glb`；手机及较慢网络使用 `j16-lite.glb`。无需 Draco/Meshopt 解码器。每版 24 个按材质合并的网格批次，贴图与几何全部内嵌，不依赖外部文件。`textures/` 是标准版烘焙贴图副本，方便后续编辑。

模型尺寸约长 20.30 m、翼展 11.90 m、高 4.499 m，单位为米。Blender 导出副本 +Z 向上、机头 -X；GLB 标准坐标 +Y 向上、机头 -X，横向翼展沿 Z。GLB 边界 X≈[-10.15,10.15]，Y≈[0,4.499]，Z≈[-5.95,5.95]。原点位于整机水平包围盒中心的地面投影，轮胎最低点 Y=0，适合直接放在转盘表面；手机版最低点误差约 0.05 mm。

## 材质与保留细节

保留完整轮廓、机翼、鸭翼、双垂尾、DSI进气道、起落架、喷口分瓣及内部叶片、座舱框架与原有座椅、武器舱轮廓和面板线。**当前歼-20源工程仅有单座座椅，未改成双座**；本次以保留原工程为准。

程序化机身迷彩烘焙为 2048²底色（sRGB/JPEG）与切线空间法线（Non-Color/OpenGL PNG）；手机版缩为 1024²。使用无光照的 EMIT 底色烘焙，不包含灯光、AO或固定投影。金属度、粗糙度、IOR等保留为 PBR 参数，金属/粗糙度是均匀数值，故没有额外金属粗糙度贴图。法线贴图带有 UV 和切线。

座舱使用 `KHR_materials_transmission`：透射约 0.83、IOR约 1.46、粗糙度约 0.13，保持烟色玻璃。采用物理透射，Alpha=1并非不透明错误。需要支持该扩展的 glTF 加载器和透射渲染（例如 Three.js GLTFLoader 的 MeshPhysicalMaterial），配合环境反射与实时灯光；避免再次降低 opacity 导致双重透明。玻璃双面显示。

材质简化：程序化节点转为有限分辨率贴图；仅保留可由 glTF PBR表达的材质参数。所有材质允许双面显示，以保留薄片和进气道内表面。标准版保留主要机身/翼面/座舱细分结果，仅减少密集小部件；手机版进一步减面，微小铆钉、喷口内叶片和曲线轮廓可能更粗糙。不是工程测量模型，尺寸描述是原模型尺寸。网格合并后不保留单独活动零件控制；V3 原工程完整保留在上述源路径。

## 网页展柜接入

GLB仅含飞机和根节点；不含玻璃柜、转盘、地面、背景、灯光或相机。网页端加载GLB后保留1米单位或对根节点统一缩放；以Y轴绕原点旋转。圆形转盘覆盖整机投影时直径至少约23.6米（同比例缩放）。
柜顶左右灯光在网页端建立，悬停时对强度作约0.8～1.2秒平滑插值；保留低强度环境反射使金属在未悬停时也可读。点击后启用轨道拖动与缩放，观察目标建议设在模型中部 `(0,2.2,0)`。原有高清渲染/细节图保留在 `images/`，它们含原摄影灯光，仅作二维详情图，不是3D底色贴图。

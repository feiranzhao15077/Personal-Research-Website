# 歼-20与雷达小车接入

## 内容与来源

- 三件真实作品按歼-16、歼-20、雷达小车排列，未占用的扇形保持无名称空位。
- 歼-20为用户提供的 V3、第1帧、鸭翼平放、起落架展开、座舱盖关闭的静态模型。旧 J16 包名和轻量版文件名在内部来源记录中保留；网页资源独立命名为 j20，机头从 -X 绕 Y 轴 +90° 转为 +Z。原歼-16网站资源不覆盖。
- R-04小车保留来源装配层级、轮轴与雷达部件，没有添加部件动画。标准版网页文件由26.89 MiB压缩到7.13 MiB，600,994三角面保留；lite为1.20 MiB、68,962三角面。
- 歼-20标准版3.40 MiB、197,877三角面；lite为1.50 MiB、97,401三角面。各生成单独入口预览档。
- 透明封面和细节图复制自用户素材，不修改像素。GLB与图片哈希、原始路径及源说明保存在 `.impeccable/model-assets/`，本机路径不放入公开源资产目录。

## 窄范围适配

- 保留已确认的圆环、展柜、灯光及顶部功能按钮。
- 高模型按柜内高度限制缩放，观察中心和取景距离随展示尺寸调整，以完整显示小车雷达与天线。
- 加载提示改用“模型”，详情元描述不再固定为飞机部件。
- 旧歼-16首图的特殊手机裁切仅用于该作品；两件新作品的照片完整适配。四张小车照片的桌面缩略图均匀分列。
- 圆环名称下移8个SVG单位，与小车轮胎留出间隔。
